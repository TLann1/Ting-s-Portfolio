# 中远海运船用装卸智能舷接平台

> 面向流体装卸作业的智能对接系统界面设计。

## Introduction

本项目为中远海运连云港流体装卸智能对接系统开展界面设计。针对原有系统界面问题，完成视觉样式重新设计，重构信息布局，调整交互操作逻辑，优化关键数据展示，完成整套工业作业系统界面和视觉组件库迭代。

This project involves interface design for the intelligent fluid loading and unloading docking system of COSCO Shipping Lianyungang. In response to the interface issues of the original system, the visual style was redesigned, the information layout was restructured, the interaction logic was adjusted, key data display was optimized, operation steps were simplified, and the interface and visual component library for the industrial operation system were iterated.

## Background

原有工业作业系统存在界面样式、信息布局、交互操作和关键数据展示方面的问题，需要对作业界面进行系统化整理和迭代。
